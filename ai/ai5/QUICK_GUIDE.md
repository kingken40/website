# Quick Guide

## Controls

- **Auto Mode:** With screen sharing on, the assistant speaks up when it spots something useful.
- **Auto-Pilot:** N.O.V.A and A.V.O.N. take turns continuing the chat.
- **Play / Pause / Stop:** Control spoken replies. These are on mobile and desktop.
- **Response Speed:** Choose Normal, Shorter Responses, or Even Shorter Responses.
- **Ready-to-use personality:** Choose a speaking style, including Sly.

## Sly

Choose **Sly** in Ready-to-use personality. Sly uses a composed, sharp, lightly witty style. Trigger lines work when Sly is selected for that assistant.

| Say or type something like | Sly may reply |
| --- | --- |
| “I’m working on a secret project.” / “My project is classified.” / “I can’t say what I’m building.” | “Working on a secret project, are we, sir?” |
| “I fixed it.” / “The bug is fixed.” / “It finally works now.” | “Excellent. The bug has been persuaded to leave. Shall we tackle the next item?” |
| “I still can’t find the bug.” / “I’m debugging this error.” | “Shall we inspect the error message first? They do tend to confess under questioning.” |
| “I have a meeting.” / “I’ve got a presentation.” | “A meeting, then. Would you like a concise briefing or a few talking points?” |
| “Thanks, that worked.” / “I appreciate it.” | “A pleasure. I shall try to appear appropriately modest.” |

These are optional conversational quips. Ask normally if you want a full answer or help with the topic.
